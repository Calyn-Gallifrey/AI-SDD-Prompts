## 接续与验证限制

1. 旧 `2.0-java8.2` 活动快照缺少执行模式时，需要重新冻结并重走受影响评审/测试；迁移测试确认不重写原批准链。已归档历史按原版本只读复核。
2. 控制器检查命令声明与证据的一致性，不认证聊天平台发件人，也不完整判断 Brief 必填项、业务设计、评审文本和测试断言的语义质量。真实用户消息、严格回合停止、人工审核及真实项目验证仍为使用前提。
3. PATH 与基线 Wrapper 属于可信工具链；本地校验和及文件锁不防御同权限恶意程序重写全部证据或绕过控制器。
4. 本轮在 Mac-Air/Corretto 8 上验证。其他操作系统和其他测试工具没有继承本次现场通过结果；无法识别的测试输出继续 blocked。
5. 旧 Word/旧 Python 仅为历史资料。未在实际内网项目、真实弱模型自主执行或阿里云桌面完成验收，不把脚本模拟结果推广为全场景可靠性保证。
