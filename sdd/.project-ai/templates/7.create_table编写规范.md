# DDL建表脚本编写规范
 
## 1. 表名命名规则
- 建议使用小写英文字母，采用下划线分隔单词
- 推荐格式：`iic_{模块}_{业务实体}`，如 `iic_ums_application_resource_api`、`iic_crm_authentication_audit`
- 避免使用数据库保留字
- 表名应具有明确的业务含义，建议使用中文注释说明表用途
 
**代码示例：**
```sql
-- 推荐的表命名示例
CREATE TABLE `iic_ums_application_resource_api` (
    `id` bigint unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
    `permission_code` varchar(80) NOT NULL DEFAULT '' COMMENT '权限编码',
    PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='权限接口表';
 
CREATE TABLE `iic_crm_authentication_audit` (
    `id` bigint unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
    `staff_id` varchar(36) NULL DEFAULT NULL COMMENT 'agentIdOrStaffId',
    PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='客户认证审核表';
```
 
## 2. 字段命名规范
- 统一使用小写英文字母，采用下划线分隔单词
- 常见字段命名建议：
  - 主键：`id`
  - 创建人：`created_by`
  - 创建时间：`created_date`
  - 更新人：`updated_by`
  - 更新时间：`updated_date`
  - 业务标识：`{业务}_id`，如 `customer_id`、`agent_id`
  - 状态字段：`status`、`is_delete`
  - 编码字段：`{业务}_code`，如 `permission_code`、`transaction_code`
 
**代码示例：**
```sql
CREATE TABLE `iic_crm_customer_interaction` (
    `id` bigint unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
    `customer_id` varchar(36) NULL DEFAULT NULL COMMENT '客户ID',
    `agent_id` varchar(36) NULL DEFAULT NULL COMMENT '操作员ID',
    `status` varchar(36) NULL DEFAULT NULL COMMENT 'Interaction状态，Open/Closed',
    `is_delete` char(1) NOT NULL DEFAULT '0' COMMENT '是否删除，1是0否',
    `permission_code` varchar(80) NOT NULL DEFAULT '' COMMENT '权限编码',
    `transaction_code` varchar(32) NULL DEFAULT NULL COMMENT '交易编码',
    `created_by` varchar(36) NOT NULL COMMENT '创建人',
    `created_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_by` varchar(36) NOT NULL COMMENT '最后修改人',
    `updated_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后修改时间',
    PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='客户interaction表';
```
 
## 3. 字段类型选择建议
- **主键字段**：推荐使用 `BIGINT UNSIGNED` 或 `INT UNSIGNED`，配合 `AUTO_INCREMENT`
- **字符串字段**：
  - 短字符串（< 256字符）：使用 `VARCHAR(n)`，建议指定长度
  - 长文本：使用 `TEXT`
  - 固定长度标识：使用 `CHAR(1)` 用于状态标识（如 0/1）
- **时间字段**：
  - 普通时间：使用 `DATETIME`，默认值建议使用 `CURRENT_TIMESTAMP`
  - 时间戳：使用 `TIMESTAMP`，可设置为 `NULL DEFAULT NULL`
- **数值字段**：
  - 计数类：使用 `INT UNSIGNED`，默认值建议为 '0'
  - 金额类：建议使用 `DECIMAL` 类型（当前样本中未出现，但建议统一）
  - 布尔标识：使用 `TINYINT(1)`，默认值建议为 0 或 1
 
**代码示例：**
```sql
CREATE TABLE `iic_crm_authentication_audit` (
    -- 主键字段：BIGINT UNSIGNED + AUTO_INCREMENT
    `id` bigint unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
 
    -- 字符串字段：VARCHAR(n) 指定长度
    `staff_id` varchar(36) NULL DEFAULT NULL COMMENT 'agentIdOrStaffId',
    `channel` varchar(150) NULL DEFAULT NULL COMMENT '渠道来源',
    `authentication_level` varchar(10) NOT NULL COMMENT '认证级别',
 
    -- 长文本字段：TEXT
    `description` text NULL DEFAULT NULL COMMENT '详细描述',
 
    -- 固定长度标识：CHAR(1)
    `is_delete` char(1) NOT NULL DEFAULT '0' COMMENT '是否删除，1是0否',
 
    -- 布尔标识：TINYINT(1)
    `open_url` tinyint(1) NOT NULL DEFAULT 1 COMMENT '是否公开url',
 
    -- 时间字段：DATETIME
    `created_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后修改时间',
 
    -- 时间戳字段：TIMESTAMP
    `attempt_begin_time` timestamp NULL DEFAULT NULL COMMENT '认证开始时间',
    `attempt_end_time` timestamp NULL DEFAULT NULL COMMENT '认证结束时间',
 
    -- 数值字段：INT UNSIGNED 计数类
    `retry_attempt_count` int unsigned NULL DEFAULT '0' COMMENT '尝试次数',
    `number_of_question_answered` int unsigned NULL DEFAULT '0' COMMENT '回答问题总数',
 
    -- 金额字段：DECIMAL（建议）
    `amount` decimal(18,4) NOT NULL DEFAULT 0.0000 COMMENT '金额',
 
    PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='客户认证审核表';
```
 
## 4. 主键与索引设计原则
- **主键**：每个表建议设置主键，推荐使用 `id` 字段作为主键
- **索引命名**：
  - 普通索引：`idx_{字段名}`，如 `idx_reference_number`
  - 唯一索引：`unique_{字段名}_idx`，如 `unique_current_contact_id_idx`
  - 业务索引：`{表简称}_{字段名}`，如 `comms_engine_created_date`
- **索引类型**：推荐使用 `BTREE` 索引
- **索引策略**：建议为常用查询字段（如 `contact_id`、`reference_number`）创建索引
 
**代码示例：**
```sql
CREATE TABLE `iic_crm_transaction` (
    `id` int NOT NULL AUTO_INCREMENT COMMENT 'id',
    `contact_id` varchar(300) NOT NULL COMMENT '呼叫ID',
    `reference_number` varchar(20) NULL DEFAULT NULL COMMENT '参考编号',
    `customer_id` varchar(32) NULL DEFAULT NULL COMMENT '客户id',
    `created_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`id`) USING BTREE,
    -- 普通索引：idx_{字段名}
    KEY `idx_reference_number` (`reference_number`),
    -- 业务索引：{表简称}_{字段名}
    KEY `contact_id_idx` (`contact_id`)
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin ROW_FORMAT=DYNAMIC COMMENT='iic_crm_transaction表';
 
CREATE TABLE `iic_call_contact_id_rel` (
    `id` bigint NOT NULL AUTO_INCREMENT COMMENT 'id',
    `original_contact_id` varchar(300) NOT NULL COMMENT '原始的呼叫ID',
    `current_contact_id` varchar(300) NOT NULL COMMENT '当前contact id',
    `created_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`id`) USING BTREE,
    -- 唯一索引：unique_{字段名}_idx
    UNIQUE KEY `unique_current_contact_id_idx` (`current_contact_id`),
    -- 普通索引
    KEY `original_contact_id_idx` (`original_contact_id`)
) ENGINE=InnoDB AUTO_INCREMENT=3 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin ROW_FORMAT=DYNAMIC COMMENT='通话记录的contact id关联关系表';
```
 
## 5. 注释规范
- **表注释**：建议在 `CREATE TABLE` 语句末尾添加 `COMMENT`，使用中文描述表用途
- **字段注释**：每个字段建议添加 `COMMENT`，使用中文描述字段含义
- 注释内容应简洁明了，避免冗余

## 6. 约束使用建议
- **NOT NULL**：关键字段建议设置为 `NOT NULL`，如主键、创建人、创建时间
- **DEFAULT**：建议为字段设置合理的默认值：
  - 字符串：`DEFAULT ''` 或 `DEFAULT NULL`
  - 数值：`DEFAULT 0` 或 `DEFAULT '0'`
  - 时间：`DEFAULT CURRENT_TIMESTAMP`
  - 更新时间：`DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP`
- **UNIQUE**：需要保证唯一性的字段建议添加唯一索引
- **CHECK**：当前样本中未使用，建议根据业务需求添加
 
**代码示例：**
```sql
CREATE TABLE `iic_ums_application_resource_api` (
    -- NOT NULL约束：主键、创建人、创建时间
    `id` int unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
    `permission_code` varchar(80) NULL DEFAULT '' COMMENT '权限编码',
    `url` varchar(200) NOT NULL DEFAULT '' COMMENT '接口url',
    `open_url` tinyint(1) NOT NULL DEFAULT 1 COMMENT '是否公开url',
 
    -- 字符串默认值：DEFAULT '' 或 DEFAULT NULL
    `created_by` varchar(32) NOT NULL DEFAULT '' COMMENT '创建人',
    `updated_by` varchar(32) NOT NULL COMMENT '最后修改人',
 
    -- 时间默认值：DEFAULT CURRENT_TIMESTAMP
    `created_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
 
    -- 更新时间默认值：DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
    `updated_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后修改时间',
```

## 7. 创建时间、更新时间字段统一要求
- **创建时间字段**：`created_date DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间'`
- **更新时间字段**：`updated_date DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后修改时间'` 或 `COMMENT '更新时间'`
- **创建人字段**：`created_by VARCHAR(n) NOT NULL DEFAULT '' COMMENT '创建人'` 或 `DEFAULT 'SYSTEM'`
- **更新人字段**：`updated_by VARCHAR(n) NOT NULL DEFAULT '' COMMENT '最后修改人'` 或 `COMMENT '更新人'`
 
**代码示例：**
```sql
-- 示例1：标准审计字段（UMS风格）
CREATE TABLE `iic_ums_application_resource_api` (
    `id` int unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
    `permission_code` varchar(80) NULL DEFAULT '' COMMENT '权限编码',
    `url` varchar(200) NOT NULL DEFAULT '' COMMENT '接口url',
    `open_url` tinyint(1) NOT NULL DEFAULT 1 COMMENT '是否公开url',
 
    -- 创建人字段：DEFAULT ''
    `created_by` varchar(32) NOT NULL DEFAULT '' COMMENT '创建人',
 
    -- 创建时间字段：DEFAULT CURRENT_TIMESTAMP
    `created_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
 
    -- 更新人字段：NOT NULL（无默认值）
    `updated_by` varchar(32) NOT NULL COMMENT '最后修改人',
 
    -- 更新时间字段：DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
    `updated_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后修改时间',
 
    PRIMARY KEY (`id`)
```

## 8. 字符集与排序规则

**代码示例：**

```sql
    `url` varchar(200) CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci NOT NULL DEFAULT '' COMMENT '接口url',
```

## 9. 存储引擎与行格式
- 存储引擎：统一使用 `ENGINE=InnoDB`
- 行格式：建议使用 `ROW_FORMAT=DYNAMIC`
- 自增起始值：可设置 `AUTO_INCREMENT=1` 或根据业务需求设置
 
**代码示例：**
```sql

    `customer_id` varchar(32) NULL DEFAULT NULL COMMENT '客户id',
    `created_by` varchar(50) NOT NULL DEFAULT 'SYSTEM' COMMENT '创建人',
    `created_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_by` varchar(50) NOT NULL DEFAULT 'SYSTEM' COMMENT '更新人',
    `updated_date` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',

    KEY `contact_id_idx` (`contact_id`),
```

## 10. 分区、分表策略建议
- 当前样本中未使用分区表
- 对于数据量大的表（如日志、审计类），建议考虑按时间范围分区
- 对于业务上可拆分的表，建议按业务维度进行分表
 
**代码示例：**

```sql
-- 示例1：按时间范围分区（适用于日志、审计类大表）
```
