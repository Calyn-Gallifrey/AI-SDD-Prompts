# 18. Code Review 设计交接约束

本节用于把设计结果传递给 `tasks.md` 和 SDD 内部 Code Review。SDD 内部 Code Review 只做代码审核与修复交接，不生成 HTML 报告。

Code Review 必须重点核对：

1. 代码落位是否符合第 5-7 节结构设计、模块划分、类 / 包 / 落位设计。
2. 数据流转是否符合第 8-11 节设计。
3. 异常处理是否符合第 12 节设计。
4. 上下文 / 审计字段是否符合第 13 节设计。
5. 测试实现是否覆盖第 14 节测试设计考量。
6. 是否出现 design 未批准的额外代码、额外目录、额外依赖。

传递给 Code Review 的高风险点：

| 风险点 | 对应设计章节 | Code Review 检查方式 |
|---|---|---|
|  |  |  |

如 Code Review 发现实现与 design 不一致，必须标记为 P1 或以上，除非该偏差已在 tasks.md 中记录并获得人工确认。
